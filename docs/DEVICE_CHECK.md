# 초기 APK 실기기 확인

현재 자동 테스트 통과는 실기기 검증을 대신하지 않습니다. 아래 항목은 아직 미검증입니다.
초기 APK는 내부 확인용 debug 빌드입니다. 실제 금융 계좌와 연결되지 않습니다.

## 설치와 첫 사용

1. APK를 Android 휴대폰으로 복사해 설치합니다. 필요한 경우 해당 파일 앱의 설치 허용을 일시적으로 설정합니다.
2. DTR을 열어 관리 금액 300,000원, 저축 0원, 다음 수입일을 오늘부터 15일 뒤로 설정합니다.
3. 오늘 배정 20,000원을 확인합니다. 8,000원 지출을 입력하면 잔여 12,000원, HP 60%여야 합니다.
4. 앱을 닫았다 열어 같은 기록이 유지되는지 확인합니다.

## 주요 점검

- 지출을 9,000원으로 수정하면 잔여 11,000원, 삭제하면 20,000원으로 복구되는지 확인합니다.
- 삭제 직후 실행 취소를 누르면 원래 지출이 복구되는지 확인합니다.
- 빠르게 저장 버튼을 여러 번 눌러도 기록이 하나인지 확인합니다.
- 고정지출 결제 후 관리 잔액과 예약액이 함께 줄고 생활비에서 두 번 차감되지 않는지 확인합니다.
- 홈 화면에 DTR 위젯을 추가하고 앱의 잔액·HP와 일치하는지 확인합니다.
- 위젯의 지출 입력 버튼을 앱 종료/실행 상태 각각에서 눌러 입력 화면이 열리는지 확인합니다.
- 위젯 갱신 실패 시에도 앱에서 저장된 기록을 확인할 수 있는지 확인합니다.
- 하루 뒤 앱 재실행 시 새 배정이 계산되는지 확인합니다. 오래된 위젯은 앱 갱신 안내를 표시해야 합니다.
- 추가 수입·저축 변경이 오늘부터 반영되고 변경 이력이 남는지 확인합니다.
- 폴더 아이콘에서 JSON 백업을 저장하고 복원 요약을 확인합니다. 복원은 현재 전체 데이터를 교체합니다.
- 파일 선택 취소 및 손상 파일 복원 거부 후 기존 기록이 유지되는지 확인합니다.
- 수입일 도달 시 새 예산 설정 안내가 나오고 자동으로 소득을 가정하지 않는지 확인합니다.
