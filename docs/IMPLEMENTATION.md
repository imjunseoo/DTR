## 순서
1. 예산 계산 엔진과 회귀 테스트, 설정 → 지출 → HP 화면, SQLite 보존.

4. 설정 변경 이력·추가 수입 처리, 통합 및 실기기 검증.
5. 사용자 관찰, 베타 서명 APK, 안내서와 테스트 결과.

OCR은 선택 목표. 회원가입·서버·은행 연동·iOS는 제외.
이 수정본에서는 수입일에 새 예산 설정을 안내한다. 자동 월 반복 및 식사/커피 환산은 승인된 후속 변경으로 별도 관리한다.

## 계산 결정
- 원 단위 정수, 날짜는 달력 날짜로 비교한다. 다음 수입일 제외.
- 당일 배정은 당일 지출 전 잔액 기준. 정수 나눗셈 잔여는 잔액에 남아 다음 날 재배분된다.
- 저축·고정지출 예약 후 생활비가 0 이하이면 HP=0, 별도 부족 상태를 표시한다.
- 고정지출은 한 번만 결제 가능. 결제금액과 예약금액이 다르면 차액은 다음 날 배분에 반영한다.
- 과거 내역 수정/삭제는 현재 주기 시작부터 재생해 이후 배정액을 복원한다.
- DB가 원장이다. 위젯 오류는 지출 저장 성공을 취소하지 않는다.
