# 2026-11-12 · 돈토리 성장 QA 인계

현재 기준은 `qa-2026-11-12-growth` 태그다. [테스트 APK와 SHA-256](https://github.com/imjunseoo/DTR/releases/tag/qa-2026-11-12-growth)은 비공개 저장소의 프리릴리스에 있다. 이 PC에서는 `C:\Users\임준서\Documents\Codex\2026-11-04\d\dontori`에서 작업한다. 다른 세션에서는 먼저 `git remote -v`, `git status -sb`와 프로젝트 루트의 pubspec.yaml을 확인한다.

## 구현된 기능

- 예산·내역: 수입일까지 하루 배정액과 잔여 HP, 보호할 저축·고정비, 지출 입력·수정·삭제, JSON 백업·복원.
- 성장: 지출을 기록한 날짜당 도토리 1개. 기록한 날이 끝났고 일일 배정액보다 적게 썼다면 1개 추가. 잔액은 기록에서 다시 계산하므로 지출 수정·삭제가 반영된다. 성장 탭에서 5개를 쓰면 한 레벨 오른다. Lv.2 새싹, Lv.5 성장 외형. 강화 횟수는 SQLite에 저장한다. DB·백업 버전 2는 버전 1의 자동 레벨을 이관한다.
- Android 홈 위젯: 3×3 기준 크기, 가용 공간에 맞춘 금액 표시, HP와 지출 입력. 여유 공간에서 24×24 스프라이트가 걷거나 멈추고 기록·휴식 포즈를 취한다. 런처의 ViewFlipper가 20프레임을 반복하며 지출·예산 상태에 따라 대사가 바뀐다. 실기기 동작은 검증 대기 중이다.

## QA 사용법과 검증 상태

1. 디버그 APK에서 상단 벌레 아이콘 → QA 시작. 제목에 QA가 보이면 임시 가계부가 활성화됐다.
2. 벌레 아이콘을 다시 열어 첫 강화 예시 → 성장 → 레벨 업. Lv.2, 잔액 0, 버튼 비활성화를 확인한다. Lv.4 예시로 반복해 Lv.5 외형을 확인한다.
3. 위젯의 표시와 지출 입력 진입을 확인한다. QA 종료 후 원래 가계부와 위젯으로 복귀하는지 확인한다. 임시 가계부는 앱 재시작 시 사라진다.
4. 일반 모드의 테스트용 기록으로 앱 재실행과 백업 왕복 후 레벨·잔액·내역을 확인한다. 복원은 대상 가계부를 교체한다.

이 버전에서 Flutter 정적 분석과 디버그 APK 빌드가 통과했다. Windows 애플리케이션 제어 정책이 flutter_tester.exe 실행을 차단해 변경 후 전체 테스트 통과 여부는 미확인이다. 초기 커밋의 20개 테스트 통과 결과는 이 버전의 결과가 아니다.
