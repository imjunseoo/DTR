## 현재 구현

- 예산과 기록: 저축·미결제 고정비를 보호해 하루 생활비와 HP를 계산한다. 지출 입력·수정·삭제·실행 취소, 예산 조정, 기기 내 SQLite 저장과 JSON 백업·복원을 제공한다.
- Figma UI: 오늘·내역·성장 탭과 예산 설정, 입력·편집, 예산 조정, 백업 화면에 크림/주황 디자인과 Noto Sans KR을 적용했다. 화면 예시는 dist/preview에 있다.
- 성장: 지출을 기록한 날에 도토리 1개, 그날 예산보다 적게 썼으면 다음 날 1개를 더 받는다. 도토리 5개로 직접 강화한다. Lv.2 새싹, Lv.5 단풍 왕관이며 이후에도 같은 비용으로 레벨이 오른다. 이전 백업의 강화 100만 회 복원 제한을 제거했다. 기록 수정·삭제 시 획득량은 재계산하고 완료된 강화는 유지한다.
- Android 홈 위젯: 날짜, 숲 산책 공간, 예산·HP, 입력 버튼 순으로 표시한다. 48dp 캐릭터가 단계별 원화로 걷고 쉬며 기록에 반응한다. 좁은 크기에서는 공간에 맞춰 산책 영역을 생략한다. 위젯에는 외형 선택에 필요한 단계까지만 전달한다.

## QA 사용법

1. 테스트 APK의 **성장 → 돈토리 성장** 제목을 길게 눌러 QA 모드를 시작한다. 임시 가계부로 전환된다.
2. 제목을 다시 길게 눌러 첫 강화 예시를 선택한다. 강화 후 Lv.2, 잔액 0, 비활성 버튼을 확인한다.
3. **Lv.4 → 7 / 왕관과 연속 강화** 예시에서는 도토리 15개로 세 번 강화한다. Lv.5에서 왕관이 나타나고 Lv.6~7에서도 왕관을 유지해야 한다.
4. QA를 종료해 실제 기록으로 돌아간다. 일반 모드에서는 테스트용 기록으로 재실행과 백업 왕복 후 레벨·잔액·내역을 확인한다. 복원은 대상 가계부를 교체한다.
